About skidzunblock

skidzunblock is a free, open-source web unblocker built on top of Ultraviolet — a powerful web proxy that routes traffic through a WISP transport. It lets you browse the web and play games directly in your browser, bypassing content filters without installing anything.


Features
• Fast in-browser proxy (Ultraviolet + WISP + libcurl transport)
• Built-in games & apps launcher
• Tab cloak (custom title & favicon) for privacy
• Multiple search engines
• Self-hostable — deploy to Railway in one click


Deploy
Fork the repo, push to GitHub, then create a new project at railway.com/new/github. The included Procfile runs node server.js and respects PORT.
